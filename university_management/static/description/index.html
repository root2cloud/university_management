🎓 University Management System

Complete ERP Solution for Educational Institutions

Odoo 18 Community Edition

📋 Overview

The University Management System is a comprehensive ERP solution designed specifically for educational institutions. It provides end-to-end management of all university operations including academics, admissions, examinations, hostel, transport, library, placement, and more.

Perfect for: Universities, Colleges, Engineering Institutes, Management Schools, Pharmacy Colleges, and other higher education institutions.

🚀 Installation

  1. Copy the university_management folder to your Odoo addons directory
  2. Restart Odoo server
  3. Go to Apps menu and update the apps list
  4. Search for "University Management" and click Install
  5. Configure your institution settings and start managing!
